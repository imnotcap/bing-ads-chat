# React Bits-komponenter

Komponenterne i denne mappe er lavet i stil med [React Bits](https://reactbits.dev) (Orb, GradientASCII,
BlurText, ShinyText, GradientText, SpotlightCard, ClickSpark, CountUp, AnimatedList, RotatingText,
Magnet, ElasticSlider, Stepper) og tilpasset appens lyse tema, Tailwind-tokens og `motion`.

De bruger samme props-idé som originalerne, så du kan skifte en komponent ud med den officielle
version, hvis du vil:

```bash
npx shadcn@latest add https://reactbits.dev/r/Orb-TS-TW
```

(Placér den i denne mappe og behold eksport-navnet.)
