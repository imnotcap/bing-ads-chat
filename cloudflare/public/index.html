Bing Ads Chat

Bing Ads Chat til Windows

Chat med en AI-assistent, der analyserer og styrer din Microsoft Advertising-konto – med forbrugsregler og godkendelse af alle ændringer.

Hent til Windows

Virker installationen ikke? Hent den klassiske installer.

Bing Ads Chat er en computer-app til Windows. Åbn denne side på din pc for at installere den.

  1. Åbn den hentede fil Bing-Ads-Chat-Setup.exe og klik Installér. Der kræves ikke administratorrettigheder.
  2. Hvis Windows viser "Windows beskyttede din pc", så klik Flere oplysninger → Kør alligevel.
  3. Start Bing Ads Chat fra Start-menuen. Har du en ældre version, installeres den nye ovenpå – samtaler og nøgler bevares.
  4. Herefter opdaterer appen sig selv – du får besked i appen, når en ny version er klar.

Kræver Windows 10 eller 11 (64-bit). Microsoft Edge WebView2 installeres automatisk, hvis den mangler.
